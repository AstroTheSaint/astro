# Link Drop - Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Open the Tool
Open `linkdrop.html` in your web browser (double-click the file or drag it into your browser).

### Step 2: Add Your API Key
1. Go to https://console.apify.com/account/integrations
2. Copy your API key
3. Paste it in the "Apify API Key" field
4. Click "Save Key"

### Step 3: Start Exporting!
1. Paste your social media links in the text area
2. Click "Fetch Data"
3. Wait for processing to complete
4. Click "Export CSV"

## 📝 Example Input

You can paste links in any format:

```
https://www.instagram.com/p/ABC123/
Check this out: https://www.tiktok.com/@user/video/123456
https://twitter.com/user/status/123 - important post
```

The system automatically extracts all URLs!

## 💡 Tips

- **Free Tier**: Apify offers free monthly credits for testing
- **Batch Size**: Process 5-20 links at a time for best results
- **Platform Support**: Works with Instagram, TikTok, Twitter, Facebook, YouTube
- **Offline Use**: Once saved, your API key works even offline (until browser cache is cleared)

## 🎯 What You Get

The CSV export includes:
- Post metrics (likes, comments, shares, views)
- User information (username, follower count, verification status)
- Content details (caption, hashtags, mentions)
- Media URLs (images, videos, thumbnails)
- Timestamps and more!
