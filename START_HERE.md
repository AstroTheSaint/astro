## 🎯 Quick Reference

### Platform Actors (Change in Link Drop)
- Instagram: `apify/instagram-scraper` (default)
- TikTok: `apify/tiktok-scraper`
- Twitter: `apify/twitter-scraper`
- Facebook: `apify/facebook-scraper`

### Best Practices
- Process 5-20 links at a time
- Wait for completion before starting new batch
- Export CSV regularly to save data
- Check Apify credit usage periodically

### Troubleshooting
- **No data?** → Check platform actor is correct
- **API error?** → Verify API key in Apify console
- **Slow processing?** → Normal for large batches
- **Missing fields?** → Some data may be private/unavailable
