# Drafting Protocol — Job 3

**Read:** `docs/MEMEFLUENCE_AGENT.md`  
**Guardrails:** `config/drafting_guardrails.md`  
**Send:** `config/email_access.md` (manual only)

---

## Workflow

```
Graded batch (APPROVED targets only)
    → draft first touch per person
    → save templates/drafts/[name].md
    → add row to templates/approval_queue.md (PENDING)
    → STOP (agent does not send)
    → Johnny reviews, edits, marks APPROVED
    → Johnny sends manually (1:1)
    → update queue + touch log
    → max 2 touches, then pause
    → call booked → handoff Johnny + Granola
```

---

## Draft file checklist

Each `templates/drafts/[name].md` must include:

- [ ] Channel choice and why
- [ ] Sender domain (memefluence.co or filmmakersworld.com) and why
- [ ] Draft text in Johnny's voice (no em dashes, no semicolons)
- [ ] Opens with specific true thing from targeting batch
- [ ] Light LA landing line + easy ask (hello, coffee, come by HQ)
- [ ] No pitch, no numbers about us, no working-opportunity ask
- [ ] One-line framing note
- [ ] Sourced specific true thing
- [ ] Touch log (max 2)
- [ ] Handoff section for post-call

---

## Voice reminder

Founder to founder. Short sentences. Direct and warm. Never salesy.

If it reads like a sequence or a pitch, rewrite as a peer saying hello.

---

## Success metric

Warm calls booked. Not messages sent.
